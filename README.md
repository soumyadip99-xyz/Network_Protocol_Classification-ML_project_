Network Protocol Classification Using Machine Learning

Project Overview

This project uses Machine Learning to classify network protocols based on network packet information.

Objective

To predict network protocols such as TCP, UDP, DNS, ARP and ICMP using packet characteristics.

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Machine Learning Algorithms

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Random Forest

Project Workflow

1. Dataset Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis
5. Feature Engineering
6. Feature Selection
7. Data Encoding
8. Train-Test Split
9. Model Training
10. Model Evaluation
11. Model Comparison
12. New Packet Prediction

Dataset

The project uses the KT GameBox network packet dataset.

Results

The accuracy of each model is calculated using the test dataset. The models are compared to identify the best-performing model.

Conclusion

This project demonstrates how Machine Learning algorithms can be used for basic network protocol classification.
